# 🔐 Simple Flutter Login App

A clean and simple Flutter application demonstrating basic user login and registration forms with local validation.

---

## ✨ Features
* **Simple UI:** Minimalist, clean login and signup forms.
* **Form Validation:** Checks for empty fields and valid email formats.
* **Navigation:** Smooth transitions between login, signup, and home screens.

---

## 🚀 How to Run

### Prerequisites
Ensure you have the Flutter SDK installed on your computer.

### Steps
1. **Clone the project:**
   ```bash
   git clone https://github.com
   cd your-repo-name
   ```

2. **Install packages:**
   ```bash
   flutter pub get
   ```

3. **Launch the app:**
   ```bash
   flutter run
   ```

---

## 📂 Code Structure
* `server.dart` — App setup and entry point.
* `public/login.html` — The login form layout.
* `public/welcome.html` — The landing screen after a successful login.
